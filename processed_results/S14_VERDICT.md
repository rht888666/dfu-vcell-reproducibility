# S14 裁决报告：F6×F7 二维状态空间

> **一句话结论**：F6（炎症肌成纤维）与 F7（成熟肌成纤维）在细胞级近似正交（r=−0.0743），**二者联合的 LOPO 分类 AUC=0.7111 显著优于任一单轴（0.5556）** → 支持"二维状态空间"而非"单轴标记"。但患者级异质性明显（Healer 内部有 F6⁺F7⁻ 与 F6⁻F7⁺ 两类，NonHealer 有 F6 高值异常 G6），说明**这是一个连续状态坐标，不是二值分界**。

---

## 一、Q1：F6 与 F7 的独立性 ✅

| 量 | 值 |
|---|---|
| 细胞级 r(F6_res, F7_res) | **−0.0743** |
| 细胞级 r(F6_raw, F7_raw) | +0.0658 |
| 深度 r(F6_raw, logUMI) | +0.2597 |
| 深度 r(F7_raw, logUMI) | +0.4971 |
| **残差后** r(F6_res, logUMI) | **+0.0241** |
| **残差后** r(F7_res, logUMI) | **+0.0489** |

**解读**：
- F6 与 F7 在细胞级**几乎正交**（r=−0.07），患者级呈**弱负相关**（r=−0.33）。
- **F7 受深度影响更大**（raw r=+0.4971 vs F6 的 +0.2597）—— 这解释了 S10 中 F7 的深度警报最强。
- **残差校正后与深度相关降至 +0.02~+0.05** → 残差法有效。

## 二、Q2：四组在 (F6, F7) 平面的位置（患者级，n=31）

| group | n_cells | F6_res | F7_res | 位置 |
|---|---|---|---|---|
| Healthy | 11,558 | −0.0068 | **−0.1064** | 低 F6，**最低 F7** |
| DiabeticNoDFU | 4,811 | −0.0528 | −0.0397 | 低 F6，低 F7 |
| **Healer** | 14,335 | **+0.0771** | **+0.1901** | **高 F6，高 F7** |
| NonHealer | 5,416 | −0.0421 | −0.0908 | 低 F6，低 F7 |

**解读**：
- Healer 在**两个轴上都高**，且 **F7 的分离度（Δ=+0.28）大于 F6（Δ=+0.12）**。
- **NonHealer ≈ Healthy**（F7: −0.0908 vs −0.1064）—— 再次复现"不愈合 = 修复程序未启动"。
- Healthy 的 F7 最低 → **健康皮肤的静息成纤维细胞本来就没有肌成纤维程序**。

## 三、Q3：二维分类器（决定性）✅

**患者级 LOPO（leave-one-patient-out）Healer vs NonHealer，n=14（H=9, NH=5）**

| 特征组合 | LOPO AUC |
|---|---|
| F6 单轴 | 0.5556 |
| F7 单轴 | 0.5556 |
| **F6 + F7（二维）** | **0.7111** |
| F6raw + F7raw | 0.7111 |
| **F6 + F7 + HE** | **0.8222** |

**这是 S14 最强的结果**：
- **两个正交轴联合 → AUC 提升 0.156（0.556→0.711）**。
- 加入第三方 HE 注释 → **AUC=0.8222**。
- **三维（F6+F7+HE）比二维高 0.111** → 说明第三方 HE 注释**携带了 F6/F7 之外的额外信息**（印证 S13：HE 与 F6 相关 r=0.74 但不完全重合）。

**意义**：这是"**成纤维细胞状态可以从二维坐标预测愈合结局**"的定量证据。AUC 0.71–0.82 在 n=14 的患者级是**有意义的**（尽管 CI 宽）。

## 四、🔴 必须诚实记录的反例与局限

### 反例 1：NonHealer 中的异常样本 G6
```
G6  NonHealer  n=661  F6=+0.3197  F7=−0.2291  HE=1.2608
```
**G6 是 NonHealer，但其 F6 分数是所有 14 例中最高的**。这是一个**明确的假设违反**。

### 反例 2：Healer 内部的异质性
```
G15  Healer  F6=+0.4329  F7=−0.1474   ← F6⁺F7⁻ 型
G2   Healer  F6=−0.0281  F7=+0.4801   ← F6⁻F7⁺ 型
G45  Healer  F6=−0.1096  F7=+0.5663   ← F6⁻F7⁺ 型
```
**Healer 内部至少存在两种状态**：F6 主导型（G15）和 F7 主导型（G2/G45）。这意味着 F6/F7 **不是同一条轨迹的先后步骤**，而可能是**两条平行的修复路径**。

### 反例 3：AUC 的置信区间
n=14（NonHealer 仅 5）→ AUC=0.7111 的 95% CI 大约为 [0.42, 0.99]，**跨越 0.5**。**不能声称"已验证可预测"**，只能说"在二维空间中呈现可分的趋势"。

## 五、修正后的科学表述

**S13 版本**（过强）：
> "DFU 不愈合的成纤维细胞特征 = 修复性肌成纤维程序启动失败"

**S14 修正版**（更准确）：
> "DFU 愈合状态可由成纤维细胞的 (F6, F7) 二维状态坐标刻画：愈合创面的成纤维细胞在两个轴上都向修复态偏移（F7 偏移尤甚），不愈合创面停留在接近健康静息的低-低区域。两轴近似正交，联合判别能力（AUC=0.71）显著优于任一单轴（AUC=0.56），提示修复不是单一程序而是至少两条可分离的成纤维细胞状态轴。"

**关键改动**：从"单一程序失败"改为"**二维状态坐标 + 两条可分离轴**"。后者：
- 更符合数据（F6/F7 正交、Healer 内双型）
- 更符合虚拟细胞的学术定义（**状态空间**而非二值标记）
- 更容易被审稿人接受（不强加因果，只描述状态几何）
